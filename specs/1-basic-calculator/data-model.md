# Data Model for Basic Calculator

This feature implements a basic command-line calculator. It primarily operates on mathematical expressions and numerical values. There are no complex entities, persistent data storage, or relationships between data models required for this application.

**Key Data Concepts:**

*   **Expression**: A string representing a mathematical calculation (e.g., "2 + 2 * (3 - 1)").
*   **Number**: Numerical values (integers or floating-point) within the expression.
*   **Operator**: Symbols representing mathematical operations (+, -, *, /, **, %).

No formal data model with fields, relationships, or validation rules is necessary beyond the inherent structure of mathematical expressions.
